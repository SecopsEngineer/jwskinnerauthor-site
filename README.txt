J.W. SKINNER AUTHOR WEBSITE

Domain: https://jwskinnerauthor.com/
Hosted by GitHub Pages. DNS remains managed in Wix. All website images are stored in assets/.

Forms use FormSubmit and send to JCSkinner246@gmail.com. Instagram review embeds load directly from Instagram and include ordinary post links as a fallback.

Canonical URLs, social metadata, sitemap, 404 links, and form return addresses use the custom domain. The older /books and /reviews URLs redirect to books.html and reviews.html.

Domain migration: configure GitHub Pages with jwskinnerauthor.com first, then update website A/CNAME records in Wix and enable Enforce HTTPS when GitHub’s certificate is available. Preserve email and unrelated DNS records.
